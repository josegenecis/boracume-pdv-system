# BoraCumê Bridge (Impressão) — Instalação

## Para que serve
O BoraCumê Bridge conecta o sistema BoraCumê com a impressora (USB ou instalada no computador), permitindo impressão automática (ex.: cozinha/KDS).

## Instalar (Windows)
1. Baixe o instalador “BoraCumê Bridge” (arquivo .exe).
2. Abra o instalador e conclua.
3. Abra o “BoraCumê Bridge” pelo atalho na Área de Trabalho.

## Vincular com o BoraCumê (1 vez)
1. No BoraCumê Bridge, clique em **Gerar código**.
2. No BoraCumê (PWA): **Configurações → Dispositivos → Impressoras → Cloud Relay**
3. Digite o código e clique em **Vincular**.
4. Clique em **Buscar impressoras** e selecione a impressora.

Pronto. O bridge fica rodando em segundo plano (ícone perto do relógio).
